# SCRATCH QUEST

子ども向けプログラミング教室のための、オリジナルScratch教材アプリです。

## 起動のしかた

`index.html` をブラウザで開くだけです。
サーバーもインストールも必要ありません。USBメモリに入れて持ち運べます。

## ファイルの役割

| ファイル | 中身 | さわる？ |
|---|---|---|
| `index.html` | 画面の骨組み | ほぼさわらない |
| `css/style.css` | 見た目・配色 | 色を変えたいときだけ |
| `js/data-basic.js` | **BASICの教材（12章）** | ★ここを編集 |
| `js/data-advance.js` | **ADVANCEの教材（12章）＋特別賞** | ★ここを編集 |
| `js/app.js` | アプリのしくみ | さわらない |

教材の中身は全部 `js/` の2つのデータファイルに入っています。
メモ帳などのテキストエディタで開いて、文章を書きかえるだけで教材が変わります。

## 章を書きかえる

`data-basic.js` の中の、変えたい章を探して文章を書きかえます。

```js
{
  month: "4月",                  // マップに出る月
  icon: "⚔️",                    // マップのアイコン（絵文字）
  title: "勇者と魔物の世界",
  world: "世界の一言説明",
  story: ["1ページ目", "2ページ目"],        // 順番に表示されるお話
  learn: [{ block: "ブロック名", why: "なぜ使うのか" }],
  missions: [
    { title: "", goal: "", hints: ["", "", ""], answer: "" }
  ],
  challenge: "発展課題",
  award: { icon: "🏆", name: "賞の名前", text: "もらったときの一言" }
}
```

- `story` は増やしても減らしてもOK（配列の要素数ぶん、ページ送りされます）
- `missions` も何個でもOK（全部クリアすると賞がもらえます）
- `hints` は3つを推奨（何個でも動きます）

## 章を追加する

`chapters: [ ... ]` の中に、上と同じ形のまとまりを `,` 区切りで足すだけです。
マップの表示も、進捗も、トロフィーも自動で増えます。

## 特別賞を追加する

`data-advance.js` の一番下の `SPECIAL_AWARDS` に足します。

```js
{ id: "sound", icon: "🎧", name: "サウンド賞", text: "音の使いかたが上手だった。" }
```

`id` は他とかぶらない英数字にしてください。

## 進捗データについて

- 記録はブラウザの localStorage に保存されます（サーバー不要）
- **パソコンごと・ブラウザごとに別々**です
- 設定画面の「記録を書きだす／読みこむ」でJSONファイルとして持ち運べます
- 教室のパソコンを子どもが共有する場合は、帰りに書きだして次回読みこむのが確実です

## 設定でできること

- **すべての章をひらく** … 順番を無視して好きな章から始められます（体験会・単発講座向け）
- **答えをかくす** … 「こたえを見る」ボタンを出さなくします（テスト・検定向け）
- **Scratchのひらきかた** … 「Scratchで作る」ボタンの飛び先URLを変えられます
